# Privacy Policy — Relax YouTube

**Effective Date:** November 19, 2026  
**Developer:** Elyas

## English

**Relax YouTube** does **not** collect, store, transmit, sell, or share any personal data, browsing history, YouTube watch history, cookies, or usage analytics.

- **No Data Collection:** The extension runs 100% locally in your browser using static CSS and JavaScript content scripts injected on `youtube.com`.
- **No Network Requests:** Relax YouTube makes zero external network requests, sends zero telemetry, and communicates with no remote servers.
- **No Local Tracking or Storage:** The extension does not read or store user profiles, account identifiers, or behavioral logs.
- **Minimal Permissions:** Relax YouTube requests zero additional browser permissions beyond injecting its content script on `youtube.com` pages.

For questions or inquiries, please open an issue in the project repository.

## Türkçe (Gizlilik Politikası)

**Relax YouTube**, hiçbir kişisel veriyi, tarama geçmişini, YouTube izleme geçmişini, çerezi veya kullanım istatistiğini **toplamaz, saklamaz, iletmez ve üçüncü taraflarla paylaşmaz**.

- **Veri Toplama Yok:** Eklenti yalnızca `youtube.com` üzerinde çalışan yerel CSS ve JavaScript içerik betiklerinden oluşur.
- **Harici Ağ İsteği Yok:** Hiçbir sunucuya veri gönderilmez ve telemetri kullanılmaz.
- **Ek İzin Yok:** Eklenti, `youtube.com` sayfalarını sadeleştirmek dışında ek tarayıcı izni talep etmez.
